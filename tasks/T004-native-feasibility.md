# T004｜原生启动与硬件可行性

负责人：Claude。审核：Codex。状态：待开始。

输入：Owner审阅的本机数据、可信恢复材料元数据、公开内核/设备树资料。还没取得材料就标明未知。

方法：核对厂商内核/配置/模块与主线候选；分析实际启动头/设备树结构；按显示、输入、温控、电源、存储、网络、GPU建立功能矩阵。相邻SoC和其他平板只作参考，不继承“已支持”结论。

验收：给出厂商内核路线和主线路线各自的具体缺口；首个启动实验说明日志出口和退出方式；无自动存储写入设计接受独立审核；没有启动通路之前不触碰设备。

输出：`reports/claude-native-feasibility.md`、硬件矩阵、一个待审核的最小实验提案。不得直接输出未经匹配的刷写命令。
